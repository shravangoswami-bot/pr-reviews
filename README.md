# Reviary reports

Public PR reviews with editable JSON and offline HTML.

Post a public PR URL on the [review inbox](https://github.com/shravangoswami-bot/pr-reviews/issues/1).
Only `shravanngoswamii`, `yebai` and `sunxd3` can request reviews.
Generated by [Reviary](https://github.com/shravanngoswamii/reviary).

[DynamicPPL example](https://shravangoswami-bot.github.io/pr-reviews/examples/dynamicppl-1529/)

Reports describe their checked revisions and limits.
Comments in downloaded HTML stay local until exported.

Bot settings are in [bot-config.json](bot-config.json).
Save changes to the `REVIARY_CONFIG` Actions variable before running the worker.
Credentials live only in this repository's Actions secrets.
