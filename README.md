# PR Lens reports

Public PR reviews with editable JSON and offline HTML.

Post a public PR URL on the [review inbox](https://github.com/shravangoswami-bot/pr-lens-reports/issues/1).
Only `shravanngoswamii`, `yebai` and `sunxd3` can request reviews.
Generated by [PR Lens](https://github.com/shravanngoswamii/pr-lens).

[DynamicPPL example](https://shravangoswami-bot.github.io/pr-lens-reports/examples/dynamicppl-1529/)

Reports describe their checked revisions and limits.
Comments in downloaded HTML stay local until exported.

Bot settings are in [bot-config.json](bot-config.json).
Save changes to the `PR_LENS_CONFIG` Actions variable before running the worker.
Credentials live only in this repository's Actions secrets.
